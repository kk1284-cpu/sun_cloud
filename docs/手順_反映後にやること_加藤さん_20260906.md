## 手順（スプレッドシート「SUN日報解析」で）

### 1. 再読み込み
ブラウザで再読み込み → メニュー **🌞 SUN日報解析** に **⑫〜⑮** が増えていることを確認。

### 2. ⑬ 設定シートを作る（1回）
「GC設定」「推進メンバー」「取込ソース」の3枚ができます。既にあるシートは触りません。

### 3. 「推進メンバー」にメールを入れる → ⑬- 共有
| メール | 氏名 | 役割 | 共有 |
|---|---|---|---|
| （石川さんのメール） | 石川 | 推進メンバー | する |

⭐ 誰を入れるかは加藤さんのご判断。入れたら **⑬- 推進メンバーに下書きフォルダを共有** を実行。
「今回追加 1名」と出れば完了。**中の37名分すべて**に効きます（親フォルダの共有は継承される）。

### 4. 「GC設定」の曜日を合わせる
既定は全部署 **土**（＝前日の**金曜17:30**に作る。今までと同じ動き）。
グループごとに違う場合は曜日を書き換えるだけです。

| 部署またはソースID | GC曜日 | 有効 |
|---|---|---|
| 薬局・ネットワーク | 土 | する |
| 輝らら | 土 | する |
| … | | |

⭐ **フォーム単位で分けたいとき**は、部署のかわりにソースIDを書けます（`yakkyoku` / `network` / `hananoaru`）。
対象期間は「GC前日までの7日間」です。

### 5. ⑭ 自動作成を毎日17:30に切り替える（1回）
金曜固定の2本（`tkGC週次トリガー` 17:00／`tkGCスライド週次トリガー` 17:30）が外れ、
**`tkGC日次トリガー`（毎日17:30）** 1本になります。ダイアログに「いまの設定」が出ます。

確認：⏱ 実行数に毎日17:30 `tkGC日次トリガー` が出る。**「本日は対象なし」のログは正常**（明日がGCの部署が無い日）。

### 6. ウェブアプリを新バージョンで再デプロイ（`?view=gc` を使う場合）
デプロイ ▾ → **デプロイを管理** → 鉛筆 → バージョン「**新バージョン**」→ デプロイ。URLは変わりません。
いまの到達マンダラのURLの `view=okr` を **`view=gc`** に変えると、下書き一覧が開きます。
（`&days=30` で遡る日数、`&group=薬局・ネットワーク` で絞り込み）

⚠ トリガーは push の瞬間から新コードですが、**`/exec` は再デプロイするまで古いまま**です。

### 7. ⑮ AIの鍵を登録（任意・後回し可）
`GEMINI_API_KEYS` `GEMINI_MODEL` `APP_TOKEN` をダイアログで入れると、スクリプトプロパティに入ります。
入れたら松山が `config.gs` の値を空にして push します（コードに鍵が残らない＝Git管理できる）。
