## 2. clasp を入れてログインする

```

```

ブラウザが開くので、送り先のアカウントで承認する。

### ⚠ `invalid_rapt` が出たら

引き継ぎ文書に、この Workspace で clasp が弾かれた記録がある。

> clasp → 貼付方式のみ（takamura-sunsun.com の再認証ポリシー `invalid_rapt`）

再認証ポリシーが有効だと、`clasp login` の途中で `invalid_rapt` になる。
出たら**深追いしない。** 貼付に切り替える（`設置手順_AppsScript_20260831.md` のステップ1）。

管理者権限があるなら、Google管理コンソール →
セキュリティ → アクセスとデータ管理 → Google Cloud セッション管理
の再認証ポリシーを一時的に緩めると通ることがある。ただし**顧客のセキュリティ設定なので、
加藤さまの了解なしに触らない。**

## 4. `.clasp.json` と `.claspignore` を置く

同じフォルダに2つ作る。

### `.clasp.json`

```json
{
  "scriptId": "1D_yTCJnSduBOmwX7eseMmUn04aXOIGWWv9RSmZTaOwgxGmSBZ3MvJ9F3",
  "rootDir": "",
  "scriptExtensions": [".js", ".gs"],
  "htmlExtensions": [".html"],
  "jsonExtensions": [".json"],
  "filePushOrder": [],
  "skipSubdirectories": false
}
```

### `.claspignore`

このリポジトリの `gas/.claspignore` をそのままコピーする。

🔴 **Drive にある7月版の `.claspignore` を使わないこと。**

取り込み・GC下書き・一括分類・フィロソフィが丸ごと抜ける。

## 5. config.gs を直す

送る前に、フォルダの中の `config.gs` を編集する。**ここが clasp の利点。**
手元のエディタで直して push すれば、ブラウザ上で書き換えなくて済む。

| 項目 | 入れる値 |
|---|---|
| `SECRET_CONFIG.GEMINI_API_KEYS` | クローバ共通キー（Drive の `config.gs` に入っている） |
| `SECRET_CONFIG.APP_TOKEN` | 推測されにくい文字列 |
| `TK.SS_ID` | `1Pg_3q14PPHMEePmzleMeD9xCNJRO8gSn2pNGSNAXHdg` |
| `TK.ADMIN_EMAIL` | `kk1284@takamura-sunsun.com` |
| `TK.GC_SLIDE.MASTER_ID` | `1Ow7HpPcVwjqZmSzv5lbzKD_h4XD5SRLUOCPq2O8A8sg` |
| `TK.GC_SLIDE.MAIL` | いったん `false`（試し打ちのあと `true` に戻す） |
| `TK.SOURCES` | 4経路。ネットワークが2種類あるので、確定するまで `ENABLED: false` |

🔴 **`config.gs` はこのリポジトリに入れない。** APIキーが直書きされている。
`.gitignore` 済みだが、手で足さないよう気をつける。

## 6. 送る

```
cd C:/Users/matsuyama/sun-gas
clasp push
```

送られたファイルの一覧が出る。**16件**であることを確かめる。

⚠ `clasp push` は**プロジェクトの中身を置き換える**。
いまは空の `コード.gs` しかないので、消えて困るものはない。

### 確かめかた

```

```

ブラウザでプロジェクトが開く。ファイル一覧に15本の `.gs` が並んでいればよい。

スプレッドシートのタブに戻って再読み込みし、
メニューバーに **🌞 SUN日報解析** が出れば成功。

## 8. 2回目以降

一度この形にしておけば、次からは手元で直して `clasp push` だけで反映できる。

```
clasp push          送る
clasp pull          ブラウザ側で直したものを取ってくる
clasp status        送る対象のファイルを一覧する
```

⭐ **ブラウザ側で直したら、次の push の前に必ず `clasp pull` する。**
push は上書きなので、pull を飛ばすとブラウザ側の修正が消える。

## つまずいたとき

| 症状 | 見るところ |
|---|---|
| `User has not enabled the Apps Script API` | 手順1 |
| `invalid_rapt` | 手順2の注意書き。貼付へ切り替える |

| `scriptId` が違うと言われる | `.clasp.json` の scriptId を確認。URLの `projects/` と `/edit` の間 |
| 関数が二重に定義されている | `MCQ113_一括貼付用.gs` を一緒に送っている。フォルダから外す |
