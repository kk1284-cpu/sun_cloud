# GCシート・チャレンジシート 運用分析

作成日: 2026-08-29
対象: SUNグループ（髙村・サンフラワーズ）のグループコーチング（GC）運用
情報源: Google ドライブ（kk1284@takamura-sunsun.com）内の関連ファイル群

---

## 0. 結論：単独の「運用マニュアル」は存在しない

`マニュアル` で検索してヒットするのは `施設内葬儀マニュアル` と `100日マニュアル` のみで、
GC・チャレンジシートの運用手順書は独立文書として存在しない。
運用ルールは後述の3か所に分散して埋め込まれている。

## 1. GCシート（グループコーチングシート）

### 1.1 実体

| 種類 | 例 | 備考 |
|---|---|---|
| 個人用スライド | `GCシート 原本` / `GCシート_氏名` / 各人版 | 1人1ファイル。四半期ごとに更新 |
| 集約用スプレッドシート | `振り返りGCシート（2026年1月～）.xlsx` 他 | 1ブックに全員のシートをタブで束ねる |
| 管理台帳 | 上記xlsxの先頭シート「GCシート管理台帳」 | 誰が・どの形式で・どの頻度で回しているかの一覧 |

### 1.2 シート構造（2層のループ）

**A. 四半期レイヤー「3ヶ月の計画と振り返り」**（ドラッカーの5つの質問がベース）

```
起こりつつある外の変化 / ミッション・パーパス / 大切にしていること
  ↓
対象・顧客は誰か → 顧客の状態（観察）→ 顧客にとっての価値 → 自らの貢献
  ↓
1ヶ月目・2ヶ月目・3ヶ月目の「成し遂げる成果」→「実践計画」→「実践結果」
  ↑ 各月の成果は〈直接の成果／価値への取り組み／人材育成〉の3分類（近年「貢献」が追加）
  ↓
想定外の成功・失敗は何か → それはどのような機会たり得るか
```

**B. 週次レイヤー「今週の振り返り」**（毎週1枚、四半期で12〜13枚）

```
ミッション・パーパス → 今週の課題 → 効果的な計画 → 実践
  → 外的変化／内的変化 → 外に生み出した成果（3分類）
  → 鍵となる発見・気づき／予期せぬ成功・失敗
  → すぐに取り組むべきこと → フィードフォワード → 今週のKey Takeaway
  → 実践に用いたフィロソフィ／ドラッカーのコンセプト → 次週の課題
```

スライド版には週次の裏に **「フィードバック貯金」** ページが挟まる
（始める／止める／増やす／減らす ＋ Key Takeaway をコピペで貯め、最終回に再確認）。

### 1.3 運用実態（管理台帳 2025-09-25 時点）

- 名簿 **115名** 中、GC参加が記録されているのは **25名**
  - 週1: 18名 / 月1: 6名 / 不定: 1名
- シート形式は **スプレッドシート15名 / グーグルスライド12名** と混在
- 台帳に記載の手順:
  - リンクの貼り方（右クリック → リンク挿入 → URL貼付、スプシは「シートと名前付き範囲」で自分のタブを指定）
  - 原本シートの注意事項: ⓪「原本」をコピーして自分のシートを作る／①改行はAlt+Enter／②自分の気づきが相手の貴重な気づきになる

## 2. チャレンジシート

2つの世代が併存している。

### 2.1 旧型：`チャレンジシート　〇〇`（Slides・35ページ）

実質はGCシートとほぼ同じ中身（マネジメントレター ＋ 3ヶ月計画 ＋ 週次振り返り×12 ＋ フィードバック貯金）。
冒頭に半期ごとの **マネジメントレター** が付くのが差分。

マネジメントレターの設問:
- 今期目標（上司が目標とすべき数字／自分が目標とすべき数字）
- 上司やチームから、どのような役割や成果を「期待」されていると「知覚」しているか
- 目標達成を妨げているものは何か
- 上司や組織が行なっていることのうち、助けになっていること／妨げになっていること

### 2.2 新型：未来会議 STM 2026.04 で導入された3スライド構成

| スライド | 内容 |
|---|---|
| **A マンダラOKR** | 中心に自身のObjective（＝「あなたは何と覚えられたいか？」）、周囲にKR1〜8を8領域固定：健康／成果1／能力1／姿勢1／成果2／能力2／姿勢2／趣味・家族。月末に達成度を色更新（赤=未着手 / 橙=取組中 / 緑=達成 / 青=超過） |
| **B マンダラチャート** | 各KRを中心に8つの具体アクションへ展開。週次振り返りの「中心課題」と連動 |
| **C ルーブリック評価表** | 各KRを Lv.1〜4 で定義。Lv.3＝「マンダラのアクションを計画通り実行しKRの数値を達成」、Lv.4＝「行動がチームに波及し期待以上の変化」 |

**明文化された書き方ルール**（数少ない成文ルール）:

- KRは「数えられる・期限がある・自分でコントロールできる」数値にする
- アクションは「〜する」形の、明日からできる小さな行動に
- NG例: 「笑顔で接する」→ 抽象的で評価不能
- OK例: 「全患者に名前で呼び、アイコンタクトをとる」
- **超重要ルール**: 書いた8つの行動が「KR（数値）につながっているか」を必ず確認する。つながっていない行動は、やっても成果にならない

記入例として薬局部門・介護部門の2つ（KR ＋ 8アクション ＋ Lv.1〜4）が付属している。

## 3. 運用の実体は3か所に分散

### 3.1 月次の場：未来会議／STM（スタイルミーティング）の進行台本

2026.04版が事実上の運行マニュアル。時間配分まで指定されている。

```
② 5分  今期の学び（ドラッカー4テーマ：貢献／コミュニケーション／目標設定／Slack対話）
③ 25分 実践シェアリング  ─ 一人2〜3分「何をした」＋「どう変わった」
        ルール：聴く側はリアクション重視、評価・アドバイスはしない
        「まだ何もできてない」も立派なシェア
④ 20分 チャレンジシート記入（スライドA→B→C）
⑤ 25分 グループコーチング・シェアリング
        前半10分 2〜3人の小グループ
          Q1 一番挑戦したいことは？
          Q2 その実現を難しくしていることは？
          Q3 相手の話を聴いて気づいたことは？
          （聴く側は評価せず、問いで深める）
        後半15分 全体シェア（一人30秒〜1分、印象的な一言だけ）
⑥ 10分 クロージング：「私は次のSTMまでに＿＿をします」を全員が声に出して宣言
        → 次回STMはこのコミットメントの振り返りから始める
```

### 3.2 理念の定義：「奈津代タイム 2026/07/02」

GCの目的を規定した唯一のテキスト。要旨:

> グループコーチングは「話を聞いてもらう場」ではなく、行動・気づき・成果を共有し
> 互いの成長につなげる場。3ヶ月目標をもとに今週の課題・行動・変化を振り返り、
> 自分は何をしたのか・そこから何を学んだのかを言語化する。
> うまくいった行動は **TTPS（徹底的にパクって進化させる）** でチーム全体の力にする。
> **AIは下書きとして活用しながら、最後は自分の言葉で整える。その考える過程こそが思考の訓練。**

### 3.3 サイクル全体

```
半期  … マネジメントレター（上司との期待のすり合わせ）
四半期… 3ヶ月計画作成 → チャレンジシート（A/B/C）作成
月次  … 未来会議／STM で共有 ＋ チャレンジシート面談 ＋ 達成度を色で更新
週次  … GCシート1枚記入 → Key Takeaway をフィードバック貯金へ蓄積
```

**チャレンジシート面談**は各リーダーの3ヶ月計画に
「④チャレンジシート面談の毎月実施」「④チャレンジシート面談実施（森・荒木・小川）」と
個別タスクとして書き込まれており、リーダーがメンバーに対して行う月次1on1として回っている。
2024年12月の未来会議では面談のロープレも実施された。

## 4. 運用上の課題

`未来会議運営 振り返り` および各GCシートの記述から抽出。

| 課題 | 根拠 |
|---|---|
| 参加率が約2割 | 115名中GC記録は25名。ほぼリーダー層に限定 |
| 形式の二重管理 | スライド15名／スプシ12名＋旧型/新型チャレンジシートの併存。集計xlsxが55MBに膨張 |
| フィードバック欄の空白 | 各シートの「フィードバックコメント」「今週のKey Takeaway」欄が実データではほぼ未記入 |
| GCが議題から落ちる | 2024-04 高村氏「前回、GCのことがなかったことを伝えたが、今回もなかった。GCは必須のものなので今後を検討して欲しい」 |
| 場がふわっとする | 2024-06 加藤雄太氏「GCの時間と認識していたがディスカッションしているだけのようにも感じられ、ふわっとしたまま終わる」→ 2026.04版でSMART／ルーブリック導入により対処された形跡 |
| 目標設定の抽象度 | 2025-03「具体的な目標が出てきていない人が多い」「具体的な目標設定に恐れがあることが分かった」 |
| 一方でAI活用は自走 | 藤田氏が2026-06に「日報からGC書式を自動作成」を自己実践、時間短縮を実感（完全自動化には未到達） |

## 5. 補足

`GC〜` 系ファイルは所有者が分散しており（各本人および複数のGmailアカウント）、
フォルダで束ねられていなかった。マイドライブ上の位置づけとしては
**管理台帳のリンクだけが唯一の索引**になっていた。

この状態を解消するため、2026-08-29 に全素材を1フォルダへ複製し、
組織別サブフォルダに整理した（`複製記録_2026-08-29.md` を参照）。
