作成 2026-08-31 ／ 松山さんの操作（10〜15分）

# なぜ今やるか

いま**無料枠（1分5回）**で動いています。今週35名が日報を書き始めると、
**判定が追いつかず、金曜の下書きが薄くなる**おそれがあります。

⚠ **設定は1本のキーだけ**です。予備キーへの切り替えは効きません。
429（上限）に当たると、そのぶんは記録されず次の実行に持ち越されます。

⭐ **④のテンプレ準備より先にやってください。** 途中でAIが止まると、
テンプレの不具合なのか無料枠なのか、切り分けが面倒になります。

---

# いくらかかるか

| 範囲 | 件数 | 概算 |
|---|---|---|
| **今週（35名×4日）** | 140件 | **約18円** |
| **月あたり（35名×20日）** | 700件 | **約91円** |
| 全社120名に広げた場合 | 2,400件 | 約312円 |

判定1件あたり、入力1,800トークン・出力120トークンほどです。

⭐ **月100円前後です。** 止まるリスクを考えれば、切り替えない理由がありません。

⚠ これは判定ぶんだけです。GC下書きの文章生成が加わると増えますが、
週1回×35名なので、**月あたり数百円の範囲**です。

# どのプロジェクトで課金するか

いま使っているのは**クローバの共通キー**です（`AQ.Ab8RN6…`）。
そのため請求は**クローバ側**に立ちます。高村さまのGoogleには影響しません。

⭐ **月100円前後なので、クローバ側で持って構わないと考えます。**
将来ほかの顧客と混ざると按分できなくなりますが、その時に分ければ済みます。

⚠ 高村さま側で持っていただく形にするなら、
**高村さまのGoogle Cloudでキーを作り直す**ことになります。今週やる作業ではありません。

# 手順

## ① キーがどのプロジェクトのものか確かめる

https://aistudio.google.com/apikey

一覧に出ているキーの**「プロジェクト」欄**を見ます。
`AQ.Ab8RN6…` で始まるキーの行です。

⚠ **ログインしているアカウントを確認してください。** クローバの共通キーなので、
それを作ったアカウントで開く必要があります。

## ② そのプロジェクトに請求先をつなぐ

https://console.cloud.google.com/billing

1. 左上のプロジェクト選択で、①で見たプロジェクトを選ぶ
2. **「請求先アカウントをリンク」**
3. 既存の請求先があればそれを選ぶ。無ければ新規に作る（カード登録）

## ③ 有料になったか確かめる

AI Studio のキー一覧に戻ると、そのキーの**プランが「従量課金」**になります。

## ④ 実際に通るか試す

スプレッドシートのメニュー **🌞 SUN日報解析** → **⑪ APIキーの診断**

**25回連続で通れば成功**です。無料枠のままなら、6回目から429で落ちます。

# 済んだあと

## 溜まっている日報を一気に片づける

有料になったら、無料枠で止まっていたぶんを流せます。

メニュー **② 未分類の日報をまとめて分類**

⚠ 件数が多いときは `tk一括分類_開始` を使います。
6分で止まっても、自分で続きのトリガーを立てて最後まで進みます。

## 進み具合を見る

メニュー **⑩ 分類の進捗を見る**

# うまくいかないとき

| 症状 | 見るところ |
|---|---|
| キー一覧にそのキーが無い | ログインしているアカウントが違う |
| 請求先がリンクできない | そのプロジェクトの編集権限があるか |
| ⑪ が6回目で落ちる | まだ無料枠。①のプロジェクトが合っているか確かめ直す |
| ⑪ が1回目から落ちる | キーの貼り間違い。`config.gs` の `GEMINI_API_KEY` |
| 503 が出る | 一時的な混雑。少し置いてやり直す |

⚠ **429 と 503 は別ものです。** 429は上限、503は混み合い。
503は有料にしても出ることがありますが、リトライで通ります。
