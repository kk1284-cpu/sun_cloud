# ① 名簿35名を貼る（10分）

`01_顧客に渡すもの/トライアルメンバー35名_貼付用_20260831.tsv`

## 貼り先

メインSS「SUN日報解析」の**「メンバー」シート**、**A2セル**から。

https://docs.google.com/spreadsheets/d/1Pg_3q14PPHMEePmzleMeD9xCNJRO8gSn2pNGSNAXHdg/edit

1行目は見出しなので、**2行目から**貼ります。TSVの1行目（見出し）は貼りません。

## なぜ最初なのか

日報フォームの名前欄は、**氏名とフィロソフィがひと続き**です。

```
大山恵子 感謝の心で
煙草 健一  楽観的に構想し 悲観的に計画し 楽観的に行動する
```

システムは名簿と突き合わせて氏名だけを取り出します。
**名簿が無いと「大山恵子 感謝の心で」がそのまま氏名になります。**

実データ7名で試したところ、**名簿が空だと6名が誤った氏名**になりました。

⚠ **一度取り込んだ行は二度目に飛ばされる**ので、あとから名簿を入れても直りません。

# ② 取り込みを1回まわす（5分）

## やること

スプレッドシート → 拡張機能 → **Apps Script**
関数の一覧から **`tk取込_全ソース`** を選んで ▶ 実行。

## 何が起きるか

- **「日報統合」シートが正しい見出し付きで作られます**
- 4経路の過去分が入ります（薬局100件超・ネットワーク282件・花のある家154件）
- 実行ログにソースごとの件数が出ます

## ⚠ これを先にやる理由がもう1つ

「日報統合」シートが無い状態でメニュー ① を押すと、**新しい日報フォームが作られます。**
先にこれを回しておけば、その心配がなくなります。

⚠ **手でシートを作って名前だけ「日報統合」にするのは避けてください。**
見出しが入らず、1件目が見出し扱いで落ちます。

## 済んだかどうかの見かた

# ④ スライドのテンプレ準備（1〜2時間）★今日の山

**ここだけが手作業です。1回だけで済みます。**

下書きは、テンプレートの `{{NAME}}` `{{THEME}}` といった**目印を差し替える方式**です。
その**13個の目印を、スライドの回答欄に人が貼る**必要があります。
回答欄は空のテキストボックスなので、コードからは狙えません。

```
顧客原本 ── 読むだけ。書き込まない
   ↓ tkGCスライド_下書きテンプレを用意() でコピー
下書き用テンプレ ── ここに13個の目印を貼る　★ここが手作業
   ↓ config の TEMPLATE_ID に設定
   ↓ tkGCスライド_個人フォルダ準備() で35名分のフォルダを作る
毎週 金17:30 ── 個人フォルダに自動で届く
```

くわしい手順は
`02_手順書・設計/MCQ113_設置手順_AppsScript_20260831.pdf` の**第3部（ステップA〜F）**

## 済んだかどうかの見かた

下書き用テンプレの各回答欄に `{{...}}` が入っていて、
config の `TEMPLATE_ID` がそのスライドのIDになっている。
