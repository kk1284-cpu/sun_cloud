## 3. gas/ を触るとき

### 3-1. 触る前に検査する

```
python3 tools/verify_gas.py
```

`gas/` の各ファイルが Drive の原本と**バイト単位で一致**しているかを見る。
サイズ照合・UTF-8の厳密デコード・`node --check` の3点。

⚠ **Drive からの取り出しは1バイト単位で取りこぼすことがある。**
実際に `コード.gs` で1バイト欠落し、日本語コメントが
「APIキーの診断」→「APIキーの訽??」に化けた。目視では気づけない。
**手で写したものを、検査を通さずにコミットしない。**

### 3-2. 原本はどちらか

いまは **Drive が原本、リポジトリが写し**。`manifest.tsv` の `pending` が残っている間はこの向き。
全件が `done` になった時点で、原本をリポジトリ側へ移す判断をする。

⚠ **その判断が済むまで、リポジトリ側の .gs を編集しない。** Drive 側で直して、写し直す。
両方を編集すると、どちらが正しいか分からなくなる。

### 3-3. 顧客のApps Scriptへ入れるとき

clasp は使えない（`takamura-sunsun.com` の再認証ポリシー `invalid_rapt`）。**貼付方式のみ。**
貼付用の1ファイル `MCQ113_一括貼付用.gs` は Drive にある。

設置手順は 引き継ぎ文書10章：
貼付 → メニュー① → ⑧ → ⑧- → ⑪ → ⑨ → 名簿
