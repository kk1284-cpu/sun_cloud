# 第0部　先に知っておく3つ

## 0-1. ⚠ ① を無条件で実行すると、5つ目のフォームが作られる

`60_setup.gs` の `SETUP_初期構築()` にこの分岐がある。

```javascript
if (!ss.getSheetByName(TK.SHEET_RAW)) {
  formInfo = tkCreateForm_(ss);      // ← 新しいGoogleフォームを作る
}
```

`TK.SHEET_RAW` は現在の `config.gs` では **`日報統合`**。
つまり **`日報統合` シートが無い状態で ① を押すと、新しい日報フォームが1本作られる。**

7月に作ったフォームが5つ目の入力先だった、というのが8/17に置き直した点。
ここでもう1本増やすと同じことが起きる。

**回避のしかた**：① より先に `tk取込_全ソース()` を実行する。
この関数は `tkEnsureSheet_(TK.SHEET_RAW, TK_UNI_HEADER)` を呼ぶので、
**正しいヘッダー付きで `日報統合` を作ってくれる。** そのあと ① を押せば分岐に入らない。

⚠ 手でシートを作って名前だけ `日報統合` にするのは避ける。
`tkEnsureSheet_` は**新規作成時にしかヘッダーを書かない**ので、
空のシートを先に作るとヘッダーなしのまま使われ、1件目が見出し扱いで落ちる。

## 0-3. ⚠ 9月4日（金）にGC下書きを出すには、手作業が1つ挟まる

`90_gcslide.gs` は **テンプレートのトークンを差し替える**方式。
`{{NAME}}` `{{THEME}}` など**13個のトークンをスライドの回答欄に人が貼る作業**が要る。
コードでは貼れない（スライドの回答欄は空のテキストボックスで、文字列置換では狙えない）。

順番はこう。

```
顧客原本（MASTER_ID）── 読むだけ。書き込まない
   ↓ tkGCスライド_下書きテンプレを用意() でコピー
下書き用テンプレ ── ここに人が13個のトークンを貼る  ★手作業・1回だけ
   ↓ TEMPLATE_ID に設定
毎週 金17:30 ── 個人フォルダに「GCシート 9/1-9/5 氏名」が置かれる
```

**この手作業を8/31に終えておかないと、9/4に下書きは出ない。**
所要は30分では収まらない。**別枠で1〜2時間を見ておく。**

⚠ `TEMPLATE_ID` に顧客原本のIDを入れると、コードが例外で止まる（原本保護のため）。
必ずコピーのIDを入れる。

# 第3部　GC下書き（スライド）の準備 ── 別枠で1〜2時間

第2部のステップ9-3 の前に、ここを終えておく。

## ステップA　顧客原本の構造を見る（書き込まない）

エディタで `tkGCスライド_構造を調べる` を実行。
`TK.GC_SLIDE.MASTER_ID` のスライド構成とテキストが実行ログに出る。
**読むだけ。原本には一切書き込まない。**

## ステップB　下書き用テンプレを作る

エディタで `tkGCスライド_下書きテンプレを用意` を実行。

作業フォルダ（`TK.GC_SLIDE.ROOT_FOLDER_ID` の下の「GC下書き」）に
`_GC下書きテンプレ（トークン入り・自動生成用）` というコピーができる。IDが実行ログに出る。

⭐ すでに同名があると作り直さない。人が入れたトークンを消さないため。

## ステップC　★手作業　13個のトークンを貼る

ステップBで作ったコピーを開き、**週次GCシートのスライドの各回答欄**に次を1つずつ貼る。

| トークン | 貼る欄 |
|---|---|
| `{{NAME}}` | 氏名 |
| `{{DEPT}}` | 部署 |
| `{{WEEK}}` | 対象週 |
| `{{COUNT}}` | 今週の日報件数 |
| `{{THEME}}` | 今週の中心課題・取り組むテーマは何か |
| `{{PRACTICE}}` | 何をどのように実践したか |
| `{{RESULT_DIRECT}}` | 外に生み出した成果 ／ 直接の成果 |
| `{{RESULT_VALUE}}` | 外に生み出した成果 ／ 価値への取り組み |
| `{{RESULT_PEOPLE}}` | 外に生み出した成果 ／ 人材育成 |
| `{{INSIGHT}}` | 鍵となる発見・気づきは何か／予期せぬ成功・失敗は？ |
| `{{PHILOSOPHY}}` | 用いたフィロソフィは |
| `{{NEXT}}` | すぐに取り組むべきことは何か |
| `{{TAKEAWAY}}` | 今週のKey Takeaway は何か |

🔴 **次の6欄には何も貼らない。空のまま残す。**

外的な変化 ／ 内的な変化 ／ 効果的な計画 ／ ドラッカーのコンセプト ／
フィロソフィ目標 ／ フィードバックコメント

⭐ ここが設計の中心。**空けるのは、AIが書けないからではなく、書かないと決めたから。**
「AIに任せる」ではなく「気づきを与える素材」として出す。書く時間を省いた分を対話に注ぐ。

⚠ 週次スライドが複数枚あるときは、**1枚だけトークンを入れて他は削除する**。
毎週このテンプレを1枚コピーして使う。

## ステップD　TEMPLATE_ID を設定

`config` の `TK.GC_SLIDE.TEMPLATE_ID` にステップBのコピーのIDを入れる。

⚠ `MASTER_ID` と同じ値を入れると、コードが「原本を書き換える事故になる」として止まる。

## ステップE　個人フォルダを作って共有

エディタで `tkGCスライド_個人フォルダ準備` を実行。

`メンバー` シートの各行について、作業フォルダの下に氏名のフォルダを作り、
`TK.GC_SLIDE.SHARE_WITH_MEMBER` が true なら本人を編集者に追加する。

⭐ **名簿が空だと何も作られない。** ステップ8を先に済ませておく。

## ステップF　先週分で試し打ち

エディタで `tkGCスライド_先週分を作る` を実行。

- 各人の個人フォルダに `GCシート 8/24-8/30 氏名` ができる
- `TK.GC_SLIDE.MAIL` が true なら本人へ案内メールが飛ぶ

⚠ **試し打ちの前に `MAIL` を false にしておく。** 本番前のものが本人に届くのを避ける。
確認できたら true に戻す。

⭐ 同名のファイルがあると作り直さない（本人が手を入れたものを消さないため）。
作り直したいときは、そのファイルを消してから再実行する。
