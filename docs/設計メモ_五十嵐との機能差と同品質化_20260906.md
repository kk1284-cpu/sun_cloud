## 3. 身分証の移行（#3）で気をつけること

- 現在の `日報統合` は `ソース#sid#行` で2,522件が既に取り込まれている
- 新しい身分証（`ソース#日時#氏名`）に切り替えると、**既存行が全部「未取込」に見えて二重に入る**
- → 切替関数 `tk取込_身分証を移行()` で、既存行の「元行」列に新キーを**上書きしてから**新方式に切り替える（五十嵐で42件の再判定に留めたのと同じ手順）
- 五十嵐は「日時＋メール」だが、高村はメール列が無いソース（ネットワーク）があるので**氏名**を使う

## 4. 鍵の置き場（#2）で気をつけること
- `tkGeminiJson_` は `SECRET_CONFIG.GEMINI_API_KEYS` を直接読んでいる → `tkSecret_(name)` を1枚かぶせ、Properties → SECRET_CONFIG の順に探す（移行期間に両方動く）
- Properties への登録は加藤さんのエディタで `tk鍵を登録()` を1回（ダイアログ入力・値はログに出さない）
- 済んだら `config.gs` の値を `''` にして、初めて git に入れられる
