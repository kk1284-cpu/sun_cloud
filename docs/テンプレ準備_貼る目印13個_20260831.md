# スライドのテンプレ準備 ── 貼る目印13個

作成 2026-08-31 ／ 加藤さまとご一緒する作業の下ごしらえ
所要 1〜2時間（1回だけ。以後は毎週自動で届きます）

---

# なぜ手作業が要るのか

下書きは、テンプレートの**目印を差し替える方式**です。
`{{NAME}}` と書いてあるところに氏名が入り、`{{THEME}}` に今週のテーマが入ります。

GCシートの回答欄は**空のテキストボックス**なので、コードから「ここが実践の欄」と
見分けられません。**最初の1回だけ、人が目印を置く**必要があります。

⭐ **置いたあとはレイアウトを自由に変えて構いません。** 目印の位置さえ動かさなければ、
文字の大きさや枠の形を変えても下書きは同じところに入ります。

---

# 進める順番

```
① tkGCスライド_構造を調べる()      いまのスライドの中身を一覧で出す
      ↓
② tkGCスライド_下書きテンプレを用意()  顧客原本を複製する（原本には書き込まない）
      ↓
③ 複製したスライドに、下の13個を貼る   ★ここが手作業
      ↓
④ config.gs の TEMPLATE_ID に複製のIDを入れる
      ↓
⑤ tkGCスライド_個人フォルダ準備()    35名分のフォルダを作って共有する
      ↓
⑥ tkGCスライド_先週分を作る()       出来上がりを1〜2名で確かめる
```

⚠ **顧客原本には書き込みません。** ②で複製したほうに貼ります。

# 貼らない欄（6つ）

**意図して空けています。** 目印を貼らないでください。

- 外的な変化 ／ 内的な変化
- 効果的な計画
- 実践に用いたドラッカーのコンセプト
- 私のフィロソフィ目標
- フィードバックコメント

⭐ **AIが書けないからではなく、書かないと決めた欄です。**
内面のことばはご本人が書く欄として残し、土曜の対話に使っていただく設計です。

# 貼り終わったら確かめること

## 数を数える

スライド上の `{{` の数が**ちょうど13個**か。多いと同じものを2回貼っています。

## つづりを見る

| よくある間違い | 正しい形 |
|---|---|
| `{ {NAME} }`（空白が入った） | `{{NAME}}` |
| `｛｛NAME｝｝`（全角） | `{{NAME}}` |
| `{{name}}`（小文字） | `{{NAME}}` |
| `{{RESULT}}`（3つを1つにした） | `{{RESULT_DIRECT}}` など3つ |

⚠ **1文字違うと、その欄だけ空になります。** エラーは出ません。

## 実物で見る

`tkGCスライド_先週分を作る()` を実行し、**1〜2名ぶんを開いて見ます。**
空の欄があれば、そこの目印のつづりを見直します。
