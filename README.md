## ソース

| 場所 | 内容 |
|---|---|
| `gas/` | Apps Script のソース。`config.gs` は入れない（`config.gs.sample` を使う） |
| `gas/manifest.tsv` | Driveの原本との対応表。ファイルID・バイト数・移送状態 |
| `tools/verify_gas.py` | `gas/` が原本とバイト単位で一致しているかの検査 |

```
python3 tools/verify_gas.py
```

Drive からの取り出しはバイトを取りこぼすことがあるため、
**gas/ に手を入れたら必ずこれを通す。**
